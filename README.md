ATM Machine Program in Python

Project Description

This is a simple ATM Machine program developed using Python. It allows users to check their account balance, withdraw money, and deposit money.

Features

* PIN verification
* Check account balance
* Withdraw money
* Deposit money
* Exit the ATM system

Technologies Used

* Python

Default PIN

1234

Starting Balance

₦10,000

How to Run the Program

1. Install Python on your computer.
2. Download the atm_machine.py file.
3. Open your terminal or command prompt.
4. Run the program using:

python atm_machine.py
